数据管理

7 个数据模块各自独立管理：下载该模块专用模板 → 上传小文件做增量更新 → 系统自动比对 新增 / 更新 / 删除 / 无变化 → 预览确认后才真正写入 → 自动生成新版本，可随时回滚上一次更新。

数据源设置

增量更新 / 版本历史 / 回滚都依赖一个 Google Apps Script 后端（档位1方案）。未连接时，看板仍可用「初始化导入」一次性加载数据，但不支持增量更新、版本与回滚。
